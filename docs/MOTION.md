# Custom PapuPay motion

The shipping asset is authored for PapuPay. It is not a stock animation.

- Editable project: `packages/motion/papupay`, generated by `scripts/build-motion.py`.
- Export: `apps/web/public/assets/papu.riv` and `apps/ios/Resources/papu.riv`.
- Artboard and state machine: `Papu`, 500 × 500, transparent.
- Data-bound view model: `PapuJourney`, with `scene` (number) and `pressed` (boolean).
- Five scenes: welcome papaya (0), QR scanner (1), food dropping into a takeaway bag (2), steaming cooking cloche (3), perforated ready receipt with check/confetti (4).
- Two state-machine layers: journey and tactile press. Pointer down/up/exit controls the spring-like illustration response.
- Seven timelines, 1,720 artboard objects, 456 keyframes; 351,982-byte export; zero validation errors or warnings.

Onboarding changes the entire illustration/copy scene. The order confirmation uses the cooking scene. The ready scene celebrates with a short readable receipt/check motion. The 3D-looking papaya is a rendered bitmap animated inside Rive, not a real-time 3D mesh.

The native app uses the worker-based Rive 6.27 runtime with a shared asynchronously loaded File. Each view has its own bound scene instance. Web uses `autoBind` and the matching view model. Offscreen/background Rive views pause; Reduced Motion shows static artwork. Web WASM and fonts are self-hosted.

Other motion uses native SwiftUI or [Motion](https://motion.dev/docs/react-animate-presence): complete screen/checkout fades and small directional movement, spring button feedback, route drawing and state feedback. Whole-app redraws no longer happen once per second. Map paths and currency formatters are cached. These changes remove identified sources of avoidable work; they are not a claim of measured 60 fps on every device.

## Editing

Follow `packages/motion/papupay/AGENTS.md` and the official Rive CLI schema. The official CLI project is reproducible and editable; the installed Rive editor can inspect exports.

```sh
python3 scripts/build-motion.py
rive packages/motion/papupay --verify
rive inspect packages/motion/papupay --summary
```

Render actual frames after editing. Scanner, basket, cooking and ready artwork were visually inspected and the exported file exercised in both applications. See the [Rive runtime documentation](https://rive.app/docs/runtimes/apple/apple).
