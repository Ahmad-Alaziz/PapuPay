# Wallet pocket

The editable Rive scene is `scene.rml`. The `Pocket` artboard has `Preview` and `Handoff` state machines for the Wallet preview and user-initiated handoff. The canonical runtime `runtime/wallet-pocket.riv` is served at `/assets/wallet-pocket.riv`. Use `runtime/wallet-pocket-still.svg` for Reduced Motion and runtime-loading states.

Rebuild with the project's Rive CLI and copy the approved `build/wallet-pocket.riv` into `runtime/wallet-pocket.riv`. Confirm both states before publishing.
